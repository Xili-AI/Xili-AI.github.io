关于我们

苏州矽励科技有限公司（Silicon Insight Technology）是一家专注 视觉智能 与 大模型应用 的技术团队。我们把计算机视觉的前沿能力与大语言模型的推理能力相结合，用工程化方法把它们沉淀为可交付、可落地的产品系统。

方向 说明
视觉智能 图像 / 视频理解、目标检测与分割、OCR、视觉大模型微调与评测
大模型应用 以 RAG 为核心的知识库工程、实体与关系抽取、智能体编排、模型微调与推理加速
工程交付 数据治理、标注流水线、服务端架构与可观测性，端到端系统交付

项目

项目 简介 技术栈
Xili-ReportRAG 🔒 质量部知识库管理系统。基于 LLM + 向量检索 + 知识图谱，从 8D 质量报告中抽取实体与关系，支持混合检索、RAG 流式问答与 AI 根因推理 Python · Flask · Qdrant · Neo4j · MinerU · Vue 3
AutoLabel 🔒 桌面端自动标注 / 模型训练工具，覆盖预训练权重加载、数据集准备、自动标注、训练与曲线查看的完整闭环 Python · tkinter · ultralytics YOLO · PyTorch · OpenCV

两个项目均为闭源仓库，仅组织成员可访问源码。
